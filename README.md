# E-mployee Operating Model — ChatGPT plugin

A ChatGPT plugin by **Dr. Jonah Tebaa**, based on his book *[The E-mployee Operating Model](https://jonahtebaa.com/blog/the-e-mployee-operating-model-book.html)* (2026, ISBN 9798172190780).

**Open it in ChatGPT:** https://chatgpt.com/plugins/plugins_6ac8d1c31e2c8191916bf02267c441cf

It turns the book's leadership instruments into 15 guided workflows. CEOs and executives use them to decide which AI work deserves a defined role, then design how that work is directed, governed, measured and owned. Each workflow ends in a table, a verdict and a list of gaps a leadership team can decide on.

| Workflow | Chapter |
|---|---|

**Data:** skills only, with no server, connector or tracking. Nothing you type reaches the developer. See the [privacy section](https://jonahtebaa.com/privacy.html#e-mployee-plugin).
